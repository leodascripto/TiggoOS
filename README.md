# TiggoOS

Research project: feasibility of a custom infotainment OS for the original head unit of the CAOA Chery Tiggo 5X Pro 2026/2027 (Brazil).

Status: phase 0, research and development environment. No firmware is built or flashed.

## Layout

| Path | Content |
|---|---|
| research/environment | Development machine reports |
| research/vehicle-hardware | Head unit hardware inventory |
| research/operating-systems | Platform comparison (AGL, Yocto, AAOS, Ubuntu Core) |
| research/drivers, research/references | Driver/BSP findings, source list |
| architecture, decisions | Proposed architecture, ADRs (only after evidence) |
| prototypes | Host-side or emulated prototypes (Qt/QML, QEMU) |
| scripts | Read-only report generators |
| docs | Roadmap and research plan |

See [docs/roadmap.md](docs/roadmap.md) and [docs/research-plan.md](docs/research-plan.md).
